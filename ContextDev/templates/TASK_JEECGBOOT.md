# JeecgBoot 任务管理文档模板 v3.0 - EARS 风格

## 模板说明

本模板采用 **EARS (Easy Approach to Requirements Syntax)** 风格，用自然语言描述任务管理，专注于"如何执行"而非管理细节。

### EARS 任务语法
```
GIVEN [任务前提] 
WHEN [任务场景]
THEN [任务执行]
WHERE [任务约束]
```

## 💡 使用说明

### 如何使用这个任务模板？

1. **明确任务目标**: 确定当前阶段要完成的主要任务
2. **分解具体任务**: 将大任务分解为可执行的小任务
3. **分配任务责任**: 明确每个任务的负责人和时间
4. **跟踪任务进度**: 定期更新任务状态和进度
5. **识别问题风险**: 及时发现和处理任务执行中的问题
6. **协调任务依赖**: 管理任务间的依赖关系
7. **验收任务成果**: 确认任务完成质量和标准

### EARS任务格式提示

- **GIVEN**: 描述任务前提，执行任务的基础条件
- **WHEN**: 描述任务场景，什么情况下执行这个任务
- **THEN**: 描述任务执行，具体要做的工作内容
- **WHERE**: 描述任务约束，时间、质量、资源等要求

### 常见问题

**Q: 任务分解应该多细？**  
A: 任务粒度要适中，既要便于管理，又要便于执行

**Q: 如何处理任务延期？**  
A: 及时分析原因，调整计划，必要时重新分配资源

**Q: 如何确保任务质量？**  
A: 建立明确的验收标准，定期检查任务成果

**注意**: 本文档采用EARS风格，专注于任务执行描述。具体任务管理工具和方法请参考对应的管理文档。
