```java
// 根据文件类型自动创建目录结构
private String buildEntryPath(CopyrightFile fileRecord) {
    String directory = switch (fileRecord.getFileType()) {
        case "source_code" -> "1-源代码/";
        case "info_form" -> "2-申报表格/";
        case "desc_doc" -> "3-说明文档/";
        default -> "其他/";
    };
    return directory + fileRecord.getFilename();
}

// 预估ZIP大小（原始大小的80%）
public long estimateZipSize(List<CopyrightFile> files) {
    long totalSize = files.stream()
            .mapToLong(f -> f.getFileSize().longValue())
            .sum();
    return (long) (totalSize * 0.8);
}
```

## 📈 业务流程

### 文件生成与下载流程
```
Agent生成文件
    ↓
调用CopyrightFileService.saveFileRecord()保存文件记录
    ↓
用户查询文件列表 (GET /apply/copyrightFile/session/{sessionId})
    ↓
用户选择下载方式:
    ├── 单文件下载 (GET /apply/copyrightFile/download/{fileId})
    │       ↓
    │   FileDownloadService.downloadFile()
    │       ↓
    │   流式返回文件
    │
    └── 批量打包下载 (GET /apply/copyrightFile/download-all/{sessionId})
            ↓
        FileZipService.packSessionFiles()
            ↓
        创建临时ZIP文件
            ↓
        流式返回ZIP文件
            ↓
        异步清理临时文件(10秒后)
```
