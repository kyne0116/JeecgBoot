## 二、测试前准备

### 2.1 确认服务状态

**后端服务：**
```bash
# 检查后端是否运行
curl http://localhost:8080/jeecg-boot/actuator/health

# 预期响应
{"status":"UP"}
```

**前端服务：**
```bash
# 检查前端是否运行
curl http://localhost:3000

# 预期响应：HTML页面内容
```

### 2.2 获取登录Token

**方法1：通过登录接口**
```bash
curl -X POST "http://localhost:8080/jeecg-boot/sys/login" \
  -H "Content-Type: application/json" \
  -d '{
    "username": "admin",
    "password": "123456"
  }'
```

**方法2：从浏览器获取**
1. 打开 http://localhost:3000
2. 登录系统
3. 打开浏览器DevTools (F12)
4. 切换到 Application 标签
5. 左侧选择 Local Storage → http://localhost:3000
6. 找到 `X-Access-Token` 字段
7. 复制Token值

### 2.3 验证权限配置

确保登录用户有访问权限：
- 页面组件：`copyright/CopyrightChatApp`
- API端点：已配置 `@PermissionData` 注解

### 3.2 创建新会话

**步骤：**
1. 点击左上角 **"+ 创建新会话"** 按钮
2. 弹出对话框
3. 输入初始需求：
   ```
   我想申报一个在线教育平台系统
   ```
4. 点击 **"创建"** 按钮

**预期结果：**
- ✅ 对话框关闭
- ✅ 左侧会话列表显示新会话卡片
- ✅ 会话状态显示：澄清中 (CLARIFYING)
- ✅ 会话卡片高亮选中
- ✅ 中间对话窗口显示加载状态

**API调用：**
```
POST /jeecg-boot/copyright/sse/session/create
参数：
  - username: 当前登录用户名
  - initialRequirement: 我想申报一个在线教育平台系统

响应示例：
{
  "success": true,
  "result": {
    "id": "user_1733216400000",
    "username": "admin",
    "status": "CLARIFYING",
    "createTime": "2025-12-03 16:00:00"
  },
  "code": 200
}
```

### 3.6 多轮对话

**预期流程：**
1. AI推送问题 (SSE事件)
2. 用户输入回答
3. 发送回答 (POST /user-input)
4. AI思考中...
5. AI推送下一个问题
6. 循环5-10轮

**典型对话示例：**
```
第1轮：
AI: 请问软件全称和简称是什么？
用户: 全称"智慧教育云平台"，简称"智教云"

第2轮：
AI: 请问软件的版本号是多少？
用户: V1.0

第3轮：
AI: 请问软件的主要功能有哪些？
用户: 在线课程、作业管理、考试系统、学习分析

第4轮：
AI: 请问软件的开发语言和技术栈？
用户: Java + Spring Boot + Vue 3

第5轮：
AI: 请问软件的用户类型有哪些？
用户: 教师、学生、管理员

...（继续澄清）

最后一轮：
AI: 需求澄清完成，开始生成文件...
```

**预期结果：**
- ✅ 每次回答后都能收到新问题
- ✅ 对话历史完整显示
- ✅ 自动滚动到最新消息
- ✅ 会话状态保持 CLARIFYING
